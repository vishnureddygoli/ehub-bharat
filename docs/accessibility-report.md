# Accessibility Report

Last reviewed: 2026-07-26

## Implemented

- `html` language set to `en-IN`.
- Skip-to-content link.
- Semantic header, main, footer, nav, sections and headings.
- Visible focus styles.
- Keyboard-operable navigation and interactive controls.
- Form labels for every field.
- Required consent checkbox.
- Form status uses `aria-live`.
- Image alt text for the approved EHUB logo.
- Text alternatives for illustrative dashboard, manufacturing and energy graphics.
- Sufficient contrast-oriented palette.
- No flashing content.
- Reduced-motion support.
- Print stylesheet.
- No accessibility overlay.

## PDF status

The PDFs are text-based and include document metadata, but the generated files are not fully tagged PDF/UA documents. A specialist tagged-PDF pass is recommended before declaring full accessible-PDF conformance.

## Manual checks still recommended

- Screen-reader spot check with VoiceOver and NVDA.
- Keyboard walkthrough on desktop and mobile.
- Browser zoom to 200 percent.
- Touch-target review on 360 px and 390 px widths.
- Colour contrast scan with final approved imagery.
- Accessible review of any future product datasheets supplied by EHUB Bharat.
